Redefining SWAP as a **vadose-zone engine with clean exchange interfaces** so
embedded models (WOFOST crop, ANIMO nutrients) become swappable *coupled
components* instead of forks compiled in. Governing ADRs:
- **ADR 0051** — SWAP-core vs coupled-component boundary (native = water/heat/
  solute + the table-driven "Plant"; components = detailed crop + nutrients).
- **ADR 0052** — nutrient subsystem **deleted** (~2.7k LoC, ~85 module globals;
  detailed nutrients → external ANIMO via the parked `.afo` output).

  mechanism that makes each coupling surface an explicit typed contract so a
  compartment's implementation can be swapped. Near-term goal: external WOFOST
  behind the `crop_water` record.
