# Architecture Decision Records

Records of significant architecture and process decisions made during the SWAP modernization.

- [ADR 0001 — gfortran-first](0001-gfortran-first.html) — Only gfortran is supported; non-GCC Fortran compilers are out of scope.
- [ADR 0002 — single builddir](0002-single-builddir.html) — Single out-of-tree build directory; no per-variant subdirs.
- [ADR 0003 — aggregator state over compartments for now](0003-aggregator-state-over-compartments-for-now.html) — Initial state design uses aggregator `swap_state_t` rather than per-compartment state.
- [ADR 0004 — pFUnit for unit tests](0004-pfunit-for-unit-tests.html) — pFUnit framework for lightweight Fortran unit tests.
- [ADR 0005 — licensing audit](0005-licensing-audit.html) — Repository licensed as GPL v2 to match upstream SWAP 4.2.0.
- [ADR 0006 — coverage tracked, not gated](0006-coverage-tracked-not-gated.html) — Coverage is a reference metric, not a CI gate.
- [ADR 0007 — config parse-validate-finalize-adapter pipeline](0007-config-validate-finalize-pipeline.html) — Four-stage input pipeline: parse, validate, finalize, adapter.
- [ADR 0008 — error collection over fatalerr](0008-error-collection-over-fatalerr.html) — Error collection for full-pass validation; one abort checkpoint after pipeline.
- [ADR 0009 — discontinue non-CSV output formats](0009-discontinue-non-csv-outputs.html) — Retire 18 legacy output switches; CSV becomes the only supported output path.
- [ADR 0010 — macropore module deferral](0010-macropore-deferral.html) — Macropore stays in legacy code; new TOML pipeline does not wire it. Schema kept as orphan infrastructure for future macropore work.
- [ADR 0011 — macropore case exclusion from regression](0011-macropore-exclusion-from-regression.html) — Case 3 dropped from check-full; ADR 0010's runtime-fallback clause superseded; Phase 4f's strangler-fig becomes a clean cut.
- [ADR 0012 — CSV companion input files](0012-csv-companion-input-files.html) — `read_csv_table` as the canonical reader for all tabular inputs in the TOML pathway; ISO date support, header validation, `error_collection_t` errors.
- [ADR 0013 — CSV meteorology input](0013-csv-meteorology-input.html) — TOML pathway reads daily meteo from a `date,rad,tmin,…,wet` CSV; legacy `.met`/`.YYY` files unchanged for the ASCII pathway.
- [ADR 0014 — readmeteo.f90 TTutil phase-out](0014-readmeteo-phaseout.html) — Three-step plan to delete all TTutil branches from `readmeteo.f90`: implement sub-daily CSV, delete dead TTutil code, clean up dead variables.
- [ADR 0015 — Strangler narrow-scope stub-errors](0015-strangler-narrow-scope-stub-errors.html) — Phase 4f legacy-reader ports default to narrow-scope coverage with validator-level stub-errors for branches no test case exercises. Legacy reader stays alive as parity-test fixture.
- [ADR 0016 — Per-rotation crop config cache](0016-per-rotation-crop-config-cache.html) — `.crp` port (Phases 1-4) loads all rotation crop content into parallel arrays on `crop_config_t` at config-load time and dispatches into the cache from `cropgrowth.f90`'s per-rotation init. Future direction: pass typed config + state to computation subs as explicit arguments, eliminating the legacy module-global mutation pattern.
- [ADR 0017 — Sibling-reader dispatch from per-rotation cache](0017-sibling-reader-dispatch-from-cache.html) — Multiple legacy readers may open the same `.crp` file (e.g. `readcropfixed` + `readarablelandgerm`). When a sibling reader is discovered (smoke-test signal: `FOPENG: File does not exist`), apply the same cache-driven dispatch at its callsite. Audit checklist updated to grep all `'.crp'` opens before each port phase.
- [ADR 0020 — Call-site gating convention](0020-call-site-gating-convention.html) — All optional subsystems are gated at the call site by an `flX` flag; subsystem implementations assume the flag is true. Brings tillage and SSDI in line with the existing pattern (flCropNut, flMacroPore, flSurfaceWater, …).
- [ADR 0021 — Tillage parameters ported to [soil.tillage] TOML block](0021-tillage-toml-port.html) — Tillage subsystem migrated from TTutil-based `swap.swp` reads to a typed `[soil.tillage]` sub-table; `Read_Tillage` retired.
- [ADR 0022 — SSDI parameters ported to [irrigation.ssdi] TOML block](0022-ssdi-toml-port.html) — SSDI subsystem migrated from TTutil-based `swap.swp` + `ssdi_file` reads to a typed `[irrigation.ssdi]` sub-table with schedule discriminator; `read_ssdi_input` and `checkdate.f90` retired.
- [ADR 0023 — TTutil retired from the build](0023-ttutil-retirement.html) — TTutil retired from the SWAP build (subproject + utility functions + reruns); `src/core/dtutil.f90` provides canonical native-Fortran date/string utilities; `fatalerr_shim.f90` renamed to canonical `fatalerr.f90`.
- [ADR 0024 — `dtutil.f90` as TTutil-API compatibility shim](0024-dtutil-compatibility-shim.html) — Documents the Phase E choice to introduce `src/core/dtutil.f90` as a same-signature shim for 11 TTutil utility functions, deferring ~75 call-site edits. Future direction: hoist utility calls out of physics layer; physics receives parsed/validated inputs only.
- [ADR 0025 — [nutrients] N1: crop-side nutrient adapter](0025-nutrients-N1-crop-side-adapter.html) — Wires wofost_nutrient_t typed config to legacy variables globals via apply_cropwofost_nutrient adapter; validator stub-error replaced with input checks. Runtime gate at tillage.f90:73 stays in place pending N2/N3.
- [ADR 0026 — [nutrients] N2a: soil-side initial state + SorpCoef](0026-nutrients-N2a-soil-side-initial-state.html) — Top-level `[nutrients]` TOML block carries initial pool concentrations (12 reals) and SorpCoef. Adapter populates legacy globals unconditionally; SorpCoef gets a deterministic default fixing a genuine uninitialised-variable bug. SoilManagement(7) `_nut.end` dump retired (broken without .snp template files).
- [ADR 0027 — [nutrients] N2b: timed amendments via CSV companion](0027-nutrients-N2b-timed-amendments.html) — Optional `events_file` on `[nutrients]` references a 4-column CSV (`date,material,amount_kgha,volat_fraction`); adapter stages, sorts, groups same-day dosages, populates legacy globals. `volat_fraction` range tightened to [0, 1] (legacy typo was [0, 500000]). Runtime path unchanged.
- [ADR 0028 — [nutrients] N3: runtime activation](0028-nutrients-N3-runtime-activation.html) — Drives legacy global `flCropNut` per-rotation from `cfg%nutrient%flcropnut` inside `cropwofost_init_from_config`; lifts validator stub at `cropwofost_init.f90:85` and runtime stub at `tillage.f90:73`. Closes the `[nutrients]` umbrella (N1+N2a+N2b+N3). Regression fixture deferred — no legacy nutrient-enabled `.crp` exists to mirror.
- [ADR 0030 — Surface-water state-type migration (pilot)](0030-state-migration-surfacewater-pilot.html) — First subsystem migrated off variables.f90 globals into typed `surfacewater_state_t` aggregated under `swap_state_t`. State threaded from `swap_main` down via argument; ASSOCIATE in compute bodies. `fldecdt` replaced by `intent(out) :: request_smaller_dt`. `qdrain` zero rule relocated to drainage `bocodre`. `l(Madr)` m→cm conversion moved to drainage TOML load. 28/29 owned globals removed from `variables.f90`. Establishes the migration playbook (discovery + design + plan + execute) for subsequent subsystem migrations.
- [ADR 0031 — Drainage state-type migration](0031-state-migration-drainage.html) — Second subsystem migrated off variables.f90 globals into typed `drainage_state_t` aggregated under `swap_state_t`. `qdra` and `qdrain` (previously misclassified into `surfacewater_state_t` per ADR 0030) moved to `drainage_state_t`. `divdra` modernized to assumed-shape arrays; all call sites pass typed state. 6 owned globals (`qdrd`, `qdrain`, `qdra`, `drainl`, `wetper`, `ztopdislay`) commented out in `variables.f90`. `geofac` adapter ordering bug fixed inline (`ipos==5` path no longer overwritten by surface_runoff field). drainage_init signature gains `config` arg (init routines now read config directly, not globals).
- [ADR 0032 — Solute state-type migration](0032-state-migration-solute.html) — Third subsystem migrated off variables.f90 globals into typed `solute_state_t` aggregated under `swap_state_t`. Phase 0 patches a real correctness gap by promoting 14 missing physics fields (`cref`, `kf`, `frexp`, `gampar`, `decpot`, `fdepth`, `ddif`, `kfsat`, `poros`, `daquif`, `decsat`, `cseeptab`, `swbr`, `cpre`) into `solute_config_t`. AgeTracer extracted to its own module with stub-error guard (preserves dead code for future reactivation). `solute_init(state)` introduced for the two-stage `cml` seeding bridge. 18 of 27 solute-owned globals commented out; 9 retained (2 for the cml/cmsy seeding bridge; 7 as AgeTracer dead-code dependencies tagged for the reactivation arc).
- [ADR 0033 — Cumulative Reset Cohorts](0033-cumulative-reset-cohorts.html) — Group cumulative balance and intermediate accumulator variables in subsystem state records into typed cohort sub-records (`<subsystem>_intermediate_t`, `<subsystem>_cumulative_t`) with type-bound `reset()` as the only method. Inline reset blocks collapse to `call state%X%cohort%reset()`. Direct field writes for accumulation. Phase A (surfacewater) complete with one finding documented: cumulative-cohort ownership asymmetry between surfacewater and drainage requires subset-zeroing at intermediate call sites; the cohort type doesn't enforce full-reset symmetry.
- [ADR 0034 — Heat subsystem state-type migration](0034-state-migration-heat.html) — Fourth subsystem migrated off `variables.f90` globals into typed flat `heat_state_t` (no cohorts — first migration without cumulative or intermediate fields). Phase 0 promotes 6 missing physics-config fields (`ddamp`, `tmean`, `tampli`, `timref`, `temtoptab`, `tembtab`) closing the `swcalt=1` silent-zero-defaults gap. `Temperature(task)` plumbed with state, closing the last main compute entry without state. `outheapar` writeback resolved as a parameter sweep (local scratch array fix); `rfcp` co-write migrated with init-order `allocated()` guard. 10+ cross-subsystem readers migrated (crop, solute, atmosphere/snow, soilhydraulics, boundary). 11 of 12 heat globals retired; `tsoil` reclassified as config-staging buffer. 871 lines of dead `csv_write`/`csv_write_tz` code deleted. check-full 5/5 byte-identical throughout.
- [ADR 0035 — Boundary subsystem state-type migration](0035-state-migration-boundary.html) — Fifth migration and first coupling-surface arc of the soil-water 4-arc decomposition (boundary → crop-uptake → atmosphere → soil-water core). 12 boundary-owned instantaneous scalar globals carved into flat `state%soilwater` (first population of the soil-water record). 8 Phase-0 config gaps closed (`sinmax/sinamp/sinave`, `cofqha/b/c`, `swcofqhc`, `hplate`). No new entry-point plumbing — `boundtop`/`BoundBottom` already took `state` (SS-HEAT Task 9 windfall). ~165 reads migrated across 8 files; ~68 dual-write legacy writes dropped. 4 compile-surfaced hidden readers resolved in Phase 2.7. Mini-sim writeback at `swapoutput.f90:3745–3820` retargeted. `pond`/`gwl`/`kmean` deferred to soil-water-core arc. check-full 5/5 byte-identical throughout.
- [ADR 0036 — Crop water uptake state-type migration](0036-state-migration-crop-uptake.html) — Sixth migration and second coupling-surface arc of the soil-water 4-arc decomposition. 23 crop-uptake-owned globals carved into `state%soilwater` (extending boundary's 12-field subset): 12 per-node arrays (`qrot`, `qpotrot`, 4 stress arrays, 6 JvL arrays), 1 two-dimensional lookup table (`mfluxtable`), 5 primary scalars (`qrosum` + 4 stress sums), 4 JvL scalars, 1 flag (`flWrtNonox`). `soilwater_init` signature bumped to `(sw, numnod, nlay)` — first per-node allocation in the record; stable for remaining arcs. `mfluxtable` build relocated from CropFixed/Wofost/Grass to the `CropGrowth(1)` dispatcher (only state-aware Task-1 caller); full relocation to `soilwater_init` blocked by init-order dependency on `SoilHydraulics(1)`. 5 compile-surfaced hidden `flWrtNonox` readers in `cropgrowth.f90` migrated via optional state arg. JvL path (`swdrought=2`) stub-errored at parse time — zero-risk migration by construction. ~131 dual-write legacy writes dropped; ~47 reads migrated across 7 files. check-full 5/5 byte-identical throughout.
- [ADR 0037 — Atmosphere subsystem state-type migration](0037-state-migration-atmosphere.html) — Seventh migration and third coupling-surface arc of the soil-water 4-arc decomposition. 40 owned globals retired (largest single-arc retirement: heat 11, boundary 12, crop-uptake 23, atmosphere 40): 22 flat scalars (11 instantaneous + 9 per-day + 3 per-event) + 8 intermediate cohort + 10 cumulative cohort. NEW `atmosphere_state_t` with TWO COHORTS (`atmosphere_intermediate_t` + `atmosphere_cumulative_t`) debuts the ADR 0033 pattern in a freshly-introduced state record (surfacewater retrofitted; atmosphere is the new-record introduction). `atmosphere_init(state%atmosphere)` wired at `swap.f90:190`. ~80+ Phase 1 dual-writes across 7 atmosphere files (et/interception/precipitation/snow/meteoday/meteodt). ~155 Phase 2 reads migrated across 9 reader files. Cohort reset consolidation collapsed 3 scattered reset blocks to 2 `reset()` calls at meteoday `ResetMetFlx`. `igrai`/`inrai` duplicate-reset in waterbalance.f90 removed. 13 compile-driven hidden readers fixed across 11 files; DoTillage/CNmethod/checkmassbal/Consolidate_Bdens gained state args. Pre-flight dual-write coverage check lesson surfaced (A-2.1 nraidt/aintcdt gap). check-full 5/5 byte-identical throughout.
- [ADR 0038 — Soil-water core state-type migration](0038-state-migration-soilwater-core.html) — Eighth migration and FINAL coupling-surface arc of the soil-water 4-arc decomposition (boundary → crop-uptake → atmosphere → core). 74 owned globals retired (largest single-arc retirement by a factor of 1.85×): 17 per-node arrays + 18 flat scalars + 22 intermediate cohort fields + 14 cumulative cohort scalars + 8 per-day fields folded into `intr` cohort. NEW `soilwater_intermediate_t` (two type-bound methods: `reset()` under `flzerointr` for all 22 fields; `reset_per_day()` under `flDayStart` for 8 per-day subset — mild ADR 0033 extension) and `soilwater_cumulative_t` ADDED TO PRE-EXISTING `soilwater_state_t` (first cohort retrofit into an existing flat record since ADR 0033 surfacewater pilot). Prior-arc deferrals resolved: `pond` (boundary D5), `gwl` (boundary D6), `kmean` full array (boundary D7), `hconduc tsoil_node` sentinel (heat ADR 0034). Mini-sim writeback in `swapoutput.f90` fully retargeted (`gwl`/`pond`/`theta`/`h` — boundary B-2.6 had covered `qbot`). 8 routines gained state args via compile-driven discovery (largest set in any arc). KEY METHODOLOGICAL ADVANCE: compile-driven retirement (Strategy B) — comment out globals in `variables.f90` first; compiler enumerates every legacy reference as a compile error; 28 iterative passes retire everything in one commit. Eliminates the which-file-first ordering hazard. Module-level pointer pattern introduced for NR-coupled utility modules (`soilhydraulicsutils.f90`, `WC_K_models_04_11.f90`) with 81+ call sites. Hupselbrook canary 1.18s. check-full 5/5 byte-identical throughout. Closes the soil-water 4-arc decomposition.
- [ADR 0039 — Tillage state-type migration](0039-state-migration-tillage.html) — Ninth migration and smallest arc to date (6 tasks, 2 compile passes, T-4 reader cutover a no-op). First arc after the soil-water 4-arc decomposition. 13 runtime-state `till_*` globals retired (Groups C+D+E): 7 per-layer allocatables + 3 per-step scalars + 3 init-once geometry/cursor integers. NEW flat `tillage_state_t` (no cohorts — all fields instantaneous) aggregated under `swap_state_t`. Groups A+B (18 config-constant `till_*` fields already in typed `soil_tillage_t`) deferred to future config-consolidation arc. Zero external readers confirmed: tillage subsystem fully self-contained across the codebase. H-4 latent bug fixed in-arc: `set_iTill` tautological condition (`Date_tillage(i-1)` vs `Date_tillage(i)`) corrected — observationally no-op in regression (all 5 cases swtill=0) but corrects multi-event tillage for users. Bdens/ParamVG cross-subsystem coupling kept as legacy. Strategy B: only 2 compile passes (smallest ever).
