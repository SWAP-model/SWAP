# Copilot Development Notes for SWAP

## CRITICAL REMINDERS

### Build System
- **ALWAYS use `pixi run` for ALL commands** in this project
- Never run `ninja`, `meson`, or other build commands directly
- Available pixi tasks:
  - `pixi run setup-ifx` - Setup Intel Fortran environment
  - `pixi run build-linux` - Build for Linux
  - `pixi run build-windows-cross` - Cross-compile for Windows
  - `pixi run test-linux-hupselbrook` - Run Hupselbrook test case
  - `pixi run clean` - Clean build

### Compiler
- Uses Intel Fortran (ifx) 2025.2.1 via pixi
- Build directory: `builddir/`
